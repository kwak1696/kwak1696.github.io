## Update

Edit `build_site.py`, update the effective date when appropriate, then run `python build_site.py` and commit generated HTML with the source. Static files are published from the root of the `main` branch using GitHub Pages. No credentials, app source, payout details, advertising scripts, analytics, games, purchases or backend services are hosted in this repository.

Keep policy statements aligned with shipped behavior. Current disclosures cover foreground GPS, optional device bearing, local map data, development-only online sharing, GMA/UMP, hosting and email inquiries. This site does not certify Google approval or replace the app's Data safety, age, consent, device-testing and production-service reviews.

GitHub Pages hosting is used for project information and documentation, not to run the game's commercial service. `app-ads.txt` discovery still depends on the developer website linked in a published store listing; a public file alone is not AdMob verification.
